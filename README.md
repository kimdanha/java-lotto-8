# java-lotto-precourse
## 💰기능 요구사항💰

### 로직 기능

- 입력받은 로또 구입 금액만틈 자동으로 로또 번호 생성
    - 1장당 번호 6개, 범위는 1~45, 오름차순
- 구매한 로또 번호들과 당첨 번호를 비교하여 각 등수(1~5등)별 일치 개수 계산
- 총 당첨 금액과 수익률(총 당첨 금액 ÷ 구입 금액 × 100) 계산
    - 수익률은 소수점 둘째 자리에서 반올림

### 입력 기능

- 로또 구입 금액 입력받음 (1,000원 단위)
- 당첨 번호 입력 받음 (쉼표 기준으로 6개 숫자)
- 보너스 번호 입력 받음 (1개 숫자)

### 출력 기능

- 발행한 로또 수량 및 번호 출력 (로또 번호는 오름차순)
- 당첨 내역 출력
- 수익률 출력

### 검증 기능 (예외 상황)

로또 금액

- 입력받은 로또 금액이 1,000원 단위인지 검증
    - 1,000원으로 나누어 떨어지지 않는 경우 예외

당첨 번호

- 입력 받은 당첨 번호가 올바른 형식인지 검증
    - 입력 받은 당첨 번호가 숫자가 아니거나, 로또 숫자 범위를 벗어나거나, 쉼표로 구분하지 않은 경우 예외
- 입력 받은 당첨 번호가 6개인지 검증
  - 입력 받은 당첨 번호가 6개가 아닌 경우 예외
- 입력받은 당첨 번호가 서로 중복되는지 검증
    - 중복되면 예외

보너스 번호

- 입력받은 보너스 번호가 올바른 형식인지 검증
    - 숫자가 아닌 경우 예외
- 6개의 당첨 번호와 중복되는지 검증
    - 중복되면 예외
